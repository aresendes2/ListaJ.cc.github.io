# Lista J — Associação de Estudantes do Colégio do Castanheiro

Este repositório contém a versão estática publicada do site da Lista J, preparada para GitHub Pages.

O site apresenta as prioridades, a equipa, as atividades e os canais oficiais da Associação de Estudantes e do Colégio do Castanheiro. Os recursos visuais necessários estão incluídos na pasta `assets/`.

## Publicação

O ficheiro `.nojekyll` assegura que o GitHub Pages serve diretamente a versão estática. Para disponibilizar uma nova versão, atualize os ficheiros do repositório e envie um commit para o ramo `main`.
